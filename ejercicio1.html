Historia del internet

  • Como funciona el internet? El internet es una red que conecta millones de dispoisitivos
  • Como funciona la web? La web es un sistema que nos permite acceder a paginas y sitios web mediante internet utilizando navegadores
  • Que es la WWW? La World Wibe Web es un sistema de paginas y recursos digitales conectados mediante enlaces

Control de versiones

  • Que es un control de versiones?

    • El control de versiones es un sistema que permite organizar, registrar y administrar los cambios en el archivo de un proyecto

HTML Basico

  • Como hacer un Documento HTLM
    1. Crear un archivo plano
    2. Añadirle la extension de archivo .html
    3. Escribir una estructura de codigo HTML
    4. Abrir el archivo HTML para visualizarlo
  • Como escribir un documento con estructura HTML

    • Para escribirlo utilizamos etiquetas de html como html, head y body, las cuales permiten organizar la estructura y el contenido de una pagina web
